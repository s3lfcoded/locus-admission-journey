---

## 🌟 О проекте

**UniPath AI** — это интеллектуальная веб-платформа, которая превращает хаос выбора университета в прозрачный персональный маршрут поступления на основе реальных данных приемных кампаний Казахстана и зарубежных грантовых программ.

В отличие от стандартных чат-ботов на базе ChatGPT, которые галлюцинируют баллами и не знают актуальных правил 2026 года, **UniPath AI** использует детерминированный скоринг-движок на TypeScript с Zod-валидацией, учитывающий:
* **Специфику ЕНТ:** 5 блоков (История Казахстана, Матграмотность, Грамотность чтения и 2 профильных предмета по 50 баллов, максимум 140).
* **Сельскую квоту («Ауыл квотасы»):** отдельный конкурс с 35% грантовых мест по IT, медицине и педагогике со своими сниженными проходными баллами.
* **Тайбрейк «Алтын белгі» и олимпиад:** гауссова модель преимущества на границе проходного балла.
* **«Честную неопределенность» (Provenance & Caveats):** честные предупреждения о скрытых расходах, дополнительных эссе и прямые ссылки на приказы/сайты вузов.

## 🚀 Сквозной пользовательский сценарий (7 этапов)

1. **Этап 1. Знакомство и выбор траектории:** выбор категории абитуриента (9–11 класс, бакалавриат в РК, поступление за рубеж).
2. **Этап 2. Интеллектуальная анкета + Быстрые демо-профили:** ползунки GPA, IELTS, ввод ЕНТ/SAT, выбор стран, бюджета и льгот (Сельская квота 35%, Алтын белгі). Поддержка быстрого переключения демо-профилей для жюри в 1 клик.
3. **Этап 3. SWOT-диагностика профиля:** оценка шансов, узких мест и рисков (дефицит баллов до ориентира, скрытые расходы на жизнь).
4. **Этап 4. Рекомендации университетов:** умная категоризация вузов на **Safety / Target / Reach** на базе 6-факторного скоринга (баллы, направление, бюджет, география, язык, рейтинг).
5. **Этап 5. Сравнение вузов бок о бок:** матрица сопоставления по дедлайнам, стоимости, требованиям к тестам и уровню достоверности данных.
6. **Этап 6. Персональный Roadmap & Экспорт дедлайнов:** интерактивный таймлайн задач со статусами (`done`, `upcoming`, `overdue`), AI-генератором мотивационных писем и экспортом календаря в `.ics`.
7. **Этап 7. Фокус на одном действии:** выделенный приоритетный шаг на сегодня с обратным отсчетом дней до критического дедлайна.

## 🛠 Технологический стек

* **Frontend:** React 18, Vite 6, Tailwind CSS, Phosphor Icons, Fontsource Inter.
* **Admission Engine SDK:** TypeScript, Zod, детерминированные алгоритмы скоринга и таймлайна.
* **Интернационализация:** полная триязычность (Русский, Казахский, Английский).
* **Тестирование:** Vitest (63 автоматизированных теста предметной логики).
* **Архитектура:** Local-first, Privacy-first (данные абитуриента сохраняются локально в `localStorage`).

## 💻 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/s3lfcoded/locus-admission-journey.git
cd locus-admission-journey

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка продакшн-бандла
npm run build

# Локальный предпросмотр продакшн-версии
npm run preview
```
