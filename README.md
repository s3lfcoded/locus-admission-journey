## 🌟 О проекте

**UniPath AI** — это интеллектуальная веб-платформа, которая превращает хаос выбора университета в прозрачный персональный маршрут поступления на основе реальных данных приемных кампаний Казахстана и зарубежных грантовых программ.

В отличие от стандартных чат-ботов на базе ChatGPT, которые галлюцинируют баллами и не знают актуальных правил 2026 года, **UniPath AI** использует детерминированный скоринг-движок на TypeScript с Zod-валидацией, учитывающий:
* **Специфику ЕНТ:** 5 блоков (История Казахстана, Матграмотность, Грамотность чтения и 2 профильных предмета по 50 баллов, максимум 140).
* **Сельскую квоту («Ауыл квотасы»):** отдельный конкурс с 35% грантовых мест по IT, медицине и педагогике со своими сниженными проходными баллами (на 15–20 пунктов ниже общего конкурса).
* **Тайбрейк «Алтын белгі» и олимпиад:** решающее преимущество при равенстве конкурсных баллов.
* **«Честную неопределенность» (Provenance & Caveats):** честные предупреждения о скрытых расходах (€6000 визовый депозит в Европе, апостиль ISEE), дополнительных эссе и прямые ссылки на приказы/сайты вузов.

## 🚀 Сквозной пользовательский сценарий (7 этапов)

1. **Этап 1. Знакомство и выбор траектории:** выбор категории абитуриента (10 класс / 11 класс / зарубежные программы).
2. **Этап 2. Интеллектуальная анкета + Быстрые демо-профили (1-Click):** 
   * Быстрые демо-профили для жюри: **Алихан** (ЕНТ 125 IT-грант РК), **Аружан** (IELTS 7.5, SAT 1420, Зарубеж $0), **Данияр** (Сельская квота 35%).
   * Ползунки GPA, IELTS, поля ЕНТ (0–140) и SAT (400–1600), выбор стран, бюджета ($0 — Только грант) и индивидуальных льгот.
3. **Этап 3. Персонализированная SWOT-диагностика:** 
   * Динамический расчет сильных сторон и зон внимания на основе введенных баллов и целей ученика. Исключает нерелевантные советы (например, предупреждения об ЕНТ для поступающих за рубеж).
4. **Этап 4. Рекомендации университетов (Safety / Target / Reach):**
   * 6-факторный скоринг соответствия (баллы, направление, бюджет, география, язык, рейтинг) с расчетом шансов в процентах.
5. **Этап 5. Сравнение вузов бок о бок:**
   * Сравнительная матрица по дедлайнам, стоимости, требованиям к тестам и уровню достоверности данных.
6. **Этап 6. Персональный Roadmap & Экспорт дедлайнов:**
   * Интерактивный таймлайн 6 задач со статусами выполнения.
   * **AI-ассистент мотивационных писем:** генерация 4-частного Personal Statement под выбранную программу.
   * **Синхронизация с календарем:** экспорт расписания дедлайнов в файл `.ics` (Apple Calendar, Google Calendar).
   * **Печатное досье:** скачивание официального верифицированного маршрута в **PDF**.
7. **Этап 7. Фокус на одном действии:**
   * Выделенный приоритетный шаг на сегодня с обратным отсчетом дней до критического дедлайна и критерием готовности (Definition of Done).

## 🛠 Технологический стек

* **Frontend:** React 19, Vite 6, Tailwind CSS, Phosphor Icons, Fontsource Inter.
* **Admission Engine SDK:** TypeScript, Zod v4, детерминированные алгоритмы скоринга и таймлайна (`src/lib/admission`).
* **Интернационализация:** полная триязычность (Русский, Казахский, Английский).
* **Тестирование:** Vitest (63 автоматизированных теста логики квот, шкал и экзаменов — 100% pass).
* **Архитектура:** Local-first, Privacy-first (все данные абитуриента защищены и сохраняются локально в `localStorage`).

## 💻 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/s3lfcoded/locus-admission-journey.git
cd locus-admission-journey

# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 5173)
npm run dev

# Запуск автотестов
npx vitest run

# Сборка продакшн-бандла
npm run build
```
